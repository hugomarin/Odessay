El problema

Crear documentos con IA se volvió fácil. Trabajar con lo que crea, no.

El modelo escribe en un minuto. Después vienen las tres horas de mover ese texto entre herramientas, y cada salto deja una copia más.

Hoy · una parada por herramienta, una copia por salto Claude · Codex spec.md copiar / pegar Google Docs exportar y enviar spec-final-v2.docx volver al agente
Con Artifact Studio · una parada agente spec.md vos filesystem · fuente de verdad sync · link · versiones

Un solo archivo, dos interfaces. La nube agrega sync, links y colaboración sin sacarlo de tu proyecto.

Qué hace

Markdown para las máquinas. Documentos para las personas.

El archivo sigue siendo Markdown en tu filesystem: portable, versionable, legible por cualquier agente. La experiencia de leerlo y editarlo no tiene por qué sentirse como Markdown.

El mismo archivo que modifica Codex es el documento que vos leés. Sin importar, sin migrar, sin una segunda fuente de verdad viviendo en otra herramienta.

Ver el método
Workspaces Un workspace, no una carpeta llena de Markdown La IA abarató producir artifacts; el problema pasó a ser saber qué tenés. Proyecto, tipo y estado en lugar de convenciones de nombres de archivo.
Editor Markdown sin la experiencia de Markdown Leés y editás un .md real en una interfaz de documento. Tus agentes reciben Markdown; vos recibís algo que se puede leer y compartir.

De cerca

No todos los artifacts son iguales, y el trabajo sobre ellos tampoco.

Tipos Un prompt no es un reporte Prompt, spec, skill, template o agente: cada tipo se comporta distinto. El tipo es una propiedad del artifact, no una carpeta más.
Notas de voz Dictá la corrección, no la escribas Marcás el fragmento, dictás qué hay que cambiar y elegís la acción: expandir, simplificar, mantener tono.
Compartir De archivo local a documento compartible Publicás el artifact y queda una URL que cualquiera abre. Compartís el documento, no otra versión del documento.
