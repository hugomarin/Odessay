Implementation notes

Removed

PUBLICATION section. Redundant with the Polish (Sparkles) panel already in the topbar. "Ready to publish" was misleading — it didn't publish, it opened a panel.

Changed — schema

STATUS → dropdown. Add new to WritingStatus + local DB migration. Trigger shows current state with icon + label. Three options: New (dashed circle) / Draft (circle) / Done (circle + check). Closes on selection.

Removed

VISIBILITY section. Public visibility doesn't exist yet in Odessay. Showing the toggle creates confusion — implies a publishing flow that isn't available. Reintroduce when public profiles ship.

Changed

SHARING → People + Preview link. Labels now clarify the distinction: People = Odessay users you invite directly. Preview link = anyone, no account needed. Same card, two subcards.

Changed

EXPORT → dropdown. Same trigger pattern as Status. "Export as…" opens Markdown / PDF / Word options. Selecting executes immediately. Note about local vs. saved is inside the popover.

Changed

SPELLCHECK → toggle. Replaces the System / Off two-button grid. Single on/off toggle row. Language hint stays as helper text below.

Order

Status → Collections → Sharing → Export → Spellcheck → Info.
